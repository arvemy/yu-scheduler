# yu-svelte

A SvelteKit project using TypeScript and Vite.

## Getting Started

### Prerequisites

Ensure you have [Bun](https://bun.sh/) installed, as this project uses `bun.lock`.

### Installation

```bash
bun install
```

### Developing

Start the development server:

```bash
bun run dev
```

### Building

To build the project for production:

```bash
bun run build
```

You can preview the built app with:

```bash
bun run preview
```
